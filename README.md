#### Things I've made

**Android**
- [droidlens](https://github.com/ESeungJun/droidlens) - A Flipper alternative that lets you inspect any Android app with just adb: screen mirroring, view hierarchy, screen flow and network. Ships with an MCP server for Claude Code agents.

**Claude Code · AI agents**
- [claude-bouncer](https://github.com/ESeungJun/claude-bouncer) - A desktop pet that bounces on screen when a Claude Code session finishes or is waiting for your input. (macOS · Windows)

**macOS · Desktop**
- [backstage](https://github.com/ESeungJun/backstage) - A menu bar app that shows everything running behind the curtain on your Mac — scheduled launchd jobs, always-on agents and background programs.
- [hopbox](https://github.com/ESeungJun/hopbox) - A little parcel box that hops between your full-screen spaces, carrying files, text and images.
- [smash](https://github.com/ESeungJun/smash) - Tidies your Downloads folder by your own rules. Every time it does, a hand comes down on the screen with a *slap!* (macOS · Windows)
- [window-scape](https://github.com/ESeungJun/window-scape) - A little window on your desktop that shows today's weather as a living low-poly landscape.

**Toss mini apps**
- Shipped 10 mini apps that run inside the Toss app — personality tests, fortune telling, a savings tracker, puzzle games and more. (private repos)

**Just for fun**
- [poketmon_idle](https://github.com/ESeungJun/poketmon_idle) - A pixel-art desktop pet you raise alongside a Pomodoro focus timer. (non-commercial fan project)
