- [smash](https://github.com/haul0214/smash) - 내가 정한 규칙대로 다운로드 폴더를 정리해 주는 앱이에요. 정리할 때마다 화면에 손바닥이 내려와 "찰싹!!" 합니다. (macOS·Windows)
- [poketmon_idle](https://github.com/haul0214/poketmon_idle) - 포모도로 타이머랑 같이 키우는 픽셀아트 데스크톱 펫이에요. (비상업 팬 프로젝트)

#### Things I made

- [droidlens](https://github.com/haul0214/droidlens) - A Flipper alternative that inspects any Android app with just adb. Screen mirroring, view hierarchy, screen navigation and network, plus an MCP server for Claude Code.
- [claude-bouncer](https://github.com/haul0214/claude-bouncer) - A pet on your screen bounces to let you know when a Claude Code session finishes or is waiting for input. (macOS · Windows)
- [window-scape](https://github.com/haul0214/window-scape) - A small window that shows today's weather as a low-poly landscape.
- [hopbox](https://github.com/haul0214/hopbox) - A parcel box that carries files, text and images between full-screen desktops.
- [backstage](https://github.com/haul0214/backstage) - Shows the scheduled and background jobs on your Mac at a glance from the menu bar.
- [smash](https://github.com/haul0214/smash) - Tidies up your Downloads folder by your own rules. Every time it cleans up, a hand comes down on the screen and goes "SMACK!!" (macOS · Windows)
- [poketmon_idle](https://github.com/haul0214/poketmon_idle) - A pixel-art desktop pet you raise alongside a Pomodoro timer. (non-commercial fan project)

#### What I mostly use
